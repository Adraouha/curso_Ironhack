Laboratorio de despliegue con Docker y maquina virtual Ubuntu en AWS

Si estas viendo esta pagina desde el navegador a traves de una direccion IP publica, significa que la conexion con el contenedor Docker en AWS EC2 ha sido exitosa.

Estado: Conectando con /api/info...

Comprobaciones cumplidas para este acceso

  1. Instancia EC2 encendida y activa en la region de AWS.
  2. Contenedor Docker ejecutandose en segundo plano.
  3. Puerto 3000 mapeado hacia el exterior mediante el modificador -p 3000:3000.
  4. Servidor Node.js escuchando en la interfaz 0.0.0.0.
  5. Security Group con regla de entrada permitiendo trafico TCP en el puerto 3000.
  6. Acceso correcto mediante la IP publica de la maquina virtual.

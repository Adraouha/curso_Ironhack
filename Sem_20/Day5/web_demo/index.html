¡Sitio web desplegado con éxito vía FileZilla & Tonohost!

Página web de prueba servida en producción desde el directorio raíz público htdocs utilizando arquitectura Cliente/Servidor, resolución DNS y el protocolo FTP.

Ver Ficha Técnica 📋
🌐

1. Resolución DNS y Red

El navegador resuelve el subdominio gratuito a una dirección IP pública mediante servidores de nombres (DNS). Luego establece una conexión HTTP/HTTPS por el puerto 80/443.

DNS → IP Pública
⚙️

2. Panel de Control (cPanel)

Configuración del hosting en Tonohost: administración de archivos, subdominios, creación de cuentas FTP asociadas y control de bases de datos MySQL.

VistaPanel / cPanel
📁

3. Transferencia FTP (FileZilla)

Conexión al puerto 21 mediante el cliente FileZilla para sincronizar los archivos (index.html, estilos.css, script.js) directamente en la carpeta htdocs.

FTP / Modo Pasivo
⚡

4. Servidor Web Apache

El servidor detecta automáticamente index.html como archivo de índice principal, permitiendo que cualquier visitante visualice la web en su navegador sin indicar la ruta completa.

Directorio /htdocs

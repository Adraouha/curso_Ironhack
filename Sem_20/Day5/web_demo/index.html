Acerca de esta pagina

Esta es una pagina web basica creada para practicar la subida de archivos a un servidor de hosting gratuito mediante el protocolo FTP.

Para que un servidor web como Apache muestre la pagina al entrar en el dominio, los archivos deben guardarse dentro de la carpeta publica htdocs y el archivo principal debe llamarse index.html.

Datos tecnicos de la conexion

Parametro Valor configurado
Servidor de hosting Tonohost (cPanel / VistaPanel)
Protocolo de transferencia FTP (File Transfer Protocol)
Puerto de conexion 21
Carpeta remota de publicacion /htdocs
Archivo principal de inicio index.html

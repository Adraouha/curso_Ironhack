Mi Proyecto de Practica con Git y GitHub

Proyecto sencillo para aprender control de versiones con Visual Studio Code.

Acerca de este proyecto

Este archivo (index.html) fue creado para practicar el flujo basico de Git: rastrear cambios (Staging), hacer commits locales y subirlos a GitHub (Push).

Pasos realizados

  1. Crear el archivo index.html.
  2. Ver el estado 'U' (Untracked) en el panel de Source Control.
  3. Pulsar el simbolo '+' para pasarlo a Staged.
  4. Escribir un mensaje y pulsar el boton Commit.
  5. Conectar con el repositorio remoto de GitHub y hacer Push.

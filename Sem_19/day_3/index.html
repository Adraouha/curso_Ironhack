Ciclo de Vida del Desarrollo de Software (SDLC)

Resumen de las seis fases principales aplicadas al proyecto de concesionario de coches del curso.

1. Planificacion

Explicacion: Consiste en organizar las tareas del proyecto, estimar el tiempo necesario y decidir que herramientas se van a utilizar.

Ejemplo en el proyecto del curso: Decidir que crearemos una aplicacion web de gestion de coches usando MySQL para la base de datos, Spring Boot para el back-end y HTML, CSS y JavaScript para el front-end, repartiendo el trabajo por semanas.

2. Analisis de requisitos

Explicacion: Se definen las funciones concretas que necesita el usuario y los datos que debe guardar el sistema antes de empezar a programar.

Ejemplo en el proyecto del curso: Acordar que cada coche tendra id, marca, modelo, matricula unica y precio, que estara relacionado con una tabla de marcas y que la web permitira listar, buscar por ID, crear, modificar, borrar e iniciar sesion.

3. Codificacion

Explicacion: Es la etapa en la que los programadores escriben el codigo fuente tanto del servidor como de la interfaz de usuario.

Ejemplo en el proyecto del curso: Programar las entidades JPA (`Coche`, `Marca`, `Usuario`), los repositorios, servicios y controladores en Java, y escribir las funciones `fetch` en JavaScript para conectar el HTML con los endpoints.

4. Documentacion

Explicacion: Consiste en redactar comentarios claros en el codigo y guias de uso para que otros desarrolladores o usuarios entiendan como funciona el programa.

Ejemplo en el proyecto del curso: Escribir el archivo `README.md` explicando como arrancar MySQL en el puerto 3306 y Spring Boot en el 8080, y comentar las funciones de JavaScript con etiquetas JSDoc.

5. Pruebas

Explicacion: Se comprueba que todas las partes de la aplicacion funcionan como se esperaba y se corrigen los errores encontrados.

Ejemplo en el proyecto del curso: Probar las peticiones `GET`, `POST`, `PUT` y `DELETE` con Postman o Bruno, ejecutar los tests de JUnit en Spring Boot y revisar con `console.log` que no aparezcan errores de CORS en el navegador.

6. Despliegue

Explicacion: Es la puesta en marcha de la aplicacion terminada en un servidor o repositorio accesible para su entrega o uso real.

Ejemplo en el proyecto del curso: Subir el codigo verificado al repositorio privado de GitHub o publicar la base de datos y la API en un servidor para que pueda utilizarse fuera del ordenador local.

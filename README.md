# Curso Ironhack - Tareas desde la Semana 17

Repositorio con las tareas organizadas por semanas y dias a partir de la semana 17, trabajando sobre el proyecto base `Jpa_Spring_has_adraou`.

## Estructura del repositorio

- `Jpa_Spring_has_adraou`: Proyecto base Spring Boot y MySQL de gestion de coches, marcas y login de usuarios con BCrypt.
- `Sem_17/day_1`: Mostrar coches con Fetch (`console.log`, un coche concreto y listado completo con `@CrossOrigin`).
- `Sem_17/day_2`: CRUD con Fetch (ver todos, buscar por ID, crear con `POST` y eliminar con `DELETE`).
- `Sem_17/day_3`: Modificar coches con `PUT` (actualizacion reutilizando `save()` y conservando la matricula si queda vacia).
- `Sem_17/day_4`: Login de usuario con Spring Security y BCrypt (`/usuarios`, `/login`, `/logout`).
- `Sem_17/day_5`: Aplicacion sencilla creada con ayuda de IA implementando unicamente `GET` y `POST` (`sorteogpt`).
- `Sem_18/day_1`: API compleja de stock de empanadas e ingredientes (`empanadas_db`).
- `Sem_18/day_2`: Chatbot Eliza mejorado con aviso «Pensando...», control de respuestas repetidas, reglas sin tildes ni mayusculas y respuesta a mensajes cortos o vacios (`eliza`).
- `Sem_18/day_3`: Consulta meteorologica con API key y `fetch` mostrando texto sencillo y protegiendo la clave con `.gitignore`.
- `Sem_18/day_4`: Generacion de elementos del DOM con `createElement()`, `classList.add()` y `appendChild()` consumiendo la API de Rick and Morty.
- `Sem_19/day_3`: Resumen del Ciclo de Vida del Desarrollo de Software (SDLC) con ejemplos del proyecto del curso.
- `Sem_19/day_4`: Documentacion de codigo JavaScript con JSDoc (`variables.js`, `funciones.js`, `jsdoc.json`, tutorial y documentacion HTML generada en `docs/`).
